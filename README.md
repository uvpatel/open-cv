## OpenCV AI Competition 2026 — powered by AWS

**Deadline:** October 26, 2026 at 11:59 PM PDT (October 27 at 12:29 PM IST)
**Prize information in the existing notes:** up to $20,250 listed on Devpost.

### Core requirements

- OpenCV 5 must perform substantive image or video analysis.
- A meaningful component must run on AWS.
- Any programming language is allowed; supporting hardware is optional.

**Practical stack:** Python, OpenCV 5, NumPy and AWS; optionally add PyTorch or another CV framework, FastAPI, React/Next.js, YOLO or another vision model, and an MCP/agent framework where useful.

### Featured paths

- **Best Use of COOL:** use the Cloud-Optimized OpenCV Library on AWS Graviton and provide evidence that COOL executes the core workload. Performance, cost and reliability evidence matter.
- **Agentic Vision:** combine OpenCV 5 with an agent. Vision output must change a subsequent decision, tool call or action. Show the workflow diagram and trace/demo; address failure handling, observability and human control.

### Submission checklist

- Technical report; judge-accessible repository or archive; pinned dependencies; build, deployment and test instructions.
- Architecture diagram and a working web endpoint or live screen-share demo.
- Video of no more than five minutes.
- Evaluation evidence, including failure cases and limitations.
- Make the vision result's effect on the next system action clear.

**Recorded fit:** best when someone on the team has strong computer-vision/data-science experience; otherwise expect a steeper learning curve.
